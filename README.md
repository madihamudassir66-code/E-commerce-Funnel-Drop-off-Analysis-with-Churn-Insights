# E-commerce-Funnel-Drop-off-Analysis-with-Churn-Insights
Worked on analyzing an e-commerce dataset to understand where users drop off in their journey.
Analyzed 50,000+ customer records to study user behavior and conversion patterns in an e-commerce environment
• Designed a behavioral funnel (Engagement → Intent → Conversion) using Excel to identify user drop-offs
• Discovered a 67% drop-off between engagement and intent stage, highlighting key conversion bottleneck
• Built an interactive Power BI dashboard to visualize funnel metrics, conversion rates, and churn insights
• Provided data-driven recommendations to improve user intent and reduce churn
Approach
Since event-level data was not available, I created a behavioral funnel using metrics like session duration, pages viewed, and cart abandonment.
Analysis
I categorized users into engaged, intent, and converted segments and calculated conversion and drop-off rates.
Key Insight
I found a major drop-off of around 67% between engagement and intent stage.
Business Impact
This indicates that users are browsing but not showing purchase intent, so improving UX, offers, or product visibility can increase conversions.
